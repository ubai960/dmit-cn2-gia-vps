## 先说清楚：什么叫"三网CN2 GIA VPS"

严格来讲，CN2 GIA 是中国电信的承载网（ChinaNet2 Global Internet Access），属于电信的高端线路，和常见的 CN2 GT 不是一回事——GT 走的是普通 163 出口，GIA 才是真正独立的高端承载网。但一台 VPS 要叫"三网 CN2 GIA"，光电信走 GIA 还不够：联通得有 9929/10099 这类精品网对接，移动得有 CMI（China Mobile International）直连。三者凑齐，才算名副其实。

DMIT 的 Premium 系列（Pro）就是按这个标准做的：洛杉矶 LAX.Pro 是三网 CN2 GIA 回程；香港 HKG.Pro 是电信 CN2 GIA + 联通 AS9929/AS10099 + 移动 CMI；东京 TYO.Pro 同样三网高端回程。三个机房覆盖的就是亚太用户最关心的三条回国路径。
